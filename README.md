# my-pachinko-project

A browser-based pachinko game with physics simulation and scoring system.

## How to play

1. Open `/home/runner/work/my-pachinko-project/my-pachinko-project/index.html` in your browser.
2. Click or tap inside the game board to launch balls.
3. Balls bounce on pins and fall into bottom pockets to earn score.
4. After all balls are used, a game-over panel appears with a restart button.
